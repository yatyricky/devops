# 修 uiH 缩放坐标混用：高度存取统一为布局像素

**根因**：saveWidgetH 用 `getBoundingClientRect().height`（屏幕像素 = 布局 × 画布缩放）写入 uiH；恢复时 `style.height = uiH px` 是布局像素——拖拽时的缩放级别和恢复时不同，高度就对不上（同一高度在不同缩放下显示也不一致）。

**改动**（web/src/DevNode.svelte saveWidgetH 一行）：
`getBoundingClientRect().height` → `offsetHeight`（布局像素，transform/画布缩放无关；border-box 下含 border，与 style.height 语义一致）。

action 侧不动（mount 设 `style.height = uiH px` 本来就是布局像素语义）。

## 验证
构建零警告；3199 实测：不同画布缩放级别下拖拽 → uiH 值一致（不随缩放变）、刷新恢复后视觉高度一致；清理 + buglog 补记 + 提交；devops-wfs/3010 不碰。
