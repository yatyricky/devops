# struct.fromjson + 审计采集器演示 wf（f2b 行改 sed，全程无 python）

## 一、struct.fromjson 节点（engine/nodes/input.js，struct 家族后追加）
- inputs `[{id:"json", type:"string", required:true}]`，outputs `[{id:"struct", type:"struct"}]`（纯 struct——运行时形状）
- run：trim 空报错 → JSON.parse（失败报错带原文前 120 字符）→ 顶层必须对象 → `ctx.markNodeOutput(node.id, JSON.stringify(obj))` → 返回 `{struct: obj}`
- node-types-untested.json 加 `struct.fromjson`；README 节点表补 dashboard.show 与 fromjson

## 二、dashboard 运行时形状派生（DevNode dashFields/dashRunObj）
- `dashFields`：源上报过 JSON（`ui.runNodeOutputs[srcId]`）→ parse → **primitive 值的键即字段列表**（type=typeof，null→string）；否则走既有编辑期派生（split 出口/形状串）
- `dashRunObj`（值源）：优先源上报 JSON，回退 `runNodeInputs[id].data`；占位文案分两种：未连线「连接 struct 提供数据」/已连线未运行「运行一次后显示字段（运行时形状）」

## 三、演示 wf（.tmp/audit-demo.json，给用户研究复制；devops-wfs 不碰）
- ssh.session（widget alias=dogyun-hongkong）+ **6 个 ssh.exec 采集器**（全部**纯 printf/grep/awk 单行，无 python**，useSudo 包裹 sudo bash -c）：
  1. sshd：`sshd -T` 取 4 key → 四 verdict 字段
  2. 防火墙+暴露面：ufw status 两 grep + ss -tlnp awk（loopback/22/80/443 白名单）
  3. nginx：cat sites-enabled 三 grep
  4. frp+deploy 权限：stat ×2（末位/中段八进制位判定）+ find world-writable 计数；{{toml}}/{{deploydir}} 动态输入接 string.const
  5. 证书：openssl enddate + date 算天数 → cert_days number
  6. 补丁+僵尸：apt -s grep -c 计数 + reboot test + ps awk
- 每采集器 → struct.fromjson → dashboard.show（便笺命名 SSHD/防火墙/NGINX/FRP权限/证书/补丁）
- task「audit-demo」全选；f2b 用法附 sed 一行：`sudo -n fail2ban-client banned | sed "s/'/\"/g"` → fromjson → dashboard
- 3199 GUI 只做渲染检查（打开/节点渲染/面板占位），**不运行任务**（真跑连远端）
