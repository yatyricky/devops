# 右侧 60% 区宽度/高度统一（用户五点）

原则：**右侧所有元素共用 60%（spacing 计入其中）；＋/－/刷新/TriSwitch 等定宽，input/select 用余下宽度**。

## app.css

1. **kv.in 与 wrow 同构**（修「input 区输入比 widgets 宽一点」）：`.kv.in { gap: 6px }`、`.kv.in .lbl { flex: 0 0 40% }`、`.inlit` 由 `width:60%+margin-left:auto` 改 `flex: 1 1 0`——与 widgets 完全同一分界线与宽度。
2. **pairrow 同构**（修「pN 比 root 宽一点/spacing 挤大」）：删 30% 定宽，改 lbl 40% 固定 + 两输入 `flex: 1 1 0` 均分 + gap 6px——p1.from/p1.to 与其它行严格对齐。
3. **stepper 按钮同高**（修「+/- 比 input 高」）：`.trow.stepper button { font-size: 12px; padding: 2px 8px; border-radius: 4px; line-height: 1.2 }`——与 input 同框。
4. **ssh/scripts picker 的 select 吃满余宽**：`.wrow > .trow select { flex: 1 1 0 }`——select 用掉 60% 里刷新按钮（定宽 flex:none）以外的全部宽度（含 spacing）；struct 编辑器等内部 trow select 不受影响。

## engine/nodes/remote.js

5. **ssh.exec 的 command widget**：kind `"text"`（textarea rows=4）→ `"string"`（单行 input）。remote.check / npm.run commands 的多行 textarea 保留（未点名）。
