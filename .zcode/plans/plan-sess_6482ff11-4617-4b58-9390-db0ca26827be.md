# Join Strings 编辑期输出推断（与 Path Resolve 同款机制）

## 现状

并行会话已建成推断基建：`App.svelte` 有 `resolvePortValue`（递归解析端口值：连线→上游，path.resolve 递归推断；未连线回读 lit）+ `inferPathResolve`（countInputs 驱动、style 风格化）；DevNode 有 `outputInfer` 渲染分支（`输出（编辑期推断）` 行）。

## 改动（两处）

1. **App.svelte**：
   - 新增 `inferStringJoin(src, depth)`——镜像引擎 run 语义（count 驱动 p1..pN，`resolvePortValue` 逐段解析，任一段不可静态确定 → undefined；`segs.join(delimiter)`）；
   - `inferOutput(nodeId)` 增加 `string.join` 分支；
   - `resolvePortValue` 的递归白名单增加 `string.join`（中间节点可被下游递归推断）。
2. **web/src/types.js** `effectiveInputs` 的 countInputs 镜像如已存在则不动（已确认支持）。

## 渲染（DevNode.svelte）

`string.join` 卡片新增「输出（编辑期推断）」行——复用现有 `outputInfer` 渲染块（`inferredOut` derived 增 string.join 分支 → `inferStringJoin(node, depth)`）。

## 验证

- `web build` + 浏览器冒烟：Join Strings 卡片接两个 输入.字符串（"a"、"b"），delimiter="-" → 推断行显示 `a-b`；改 delimiter → 实时更新；断开任一段 → 推断行消失。
- `npm run verify` 保持跑绿。
