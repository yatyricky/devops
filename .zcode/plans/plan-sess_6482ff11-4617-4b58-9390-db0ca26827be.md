# 修 textarea 自适应高度的滚动条（border 2px 补偿）

**改动**：web/src/lib/textareaEnhance.js 的 fit()——`height = min(scrollHeight, max)` 改为 `height = min(scrollHeight + 2, max)`（+2 = 上下 border 补偿，border-box 下 clientHeight 才能与 scrollHeight 对齐；gutter/pre 随容器自动跟高，对齐不变）。

**验证**：构建；3199 实测（长命令卡 scrollHeight 状态下 clientHeight ≥ scrollHeight、无纵向滚动条）；清理 + 提交。
