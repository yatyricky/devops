# Make Struct → Selector → Split Struct 链的编辑期 string 值推导

## 背景（xlgbis.json 只读核查确认）
`makeq7031`（alias="tencent-shanghai" 等常量字段）→ `onex4f63`（pick="in1"）→ `splitp7cb1` → `sessionidp01.alias`（string 输入口）。当前输入口预览显示「（运行时）」——`resolvePortValue` 对源为 select.one/struct.split/struct.make 的连线无值可取（三处断链）。推导打通后，**ssh 别名防漂移门禁也恢复工作**（此前这类输入 resolvePortValue=undefined 直接跳过校验）。

## 实现（仅 web/src/lib/infer.js，消费端零改动自动生效）

1. **新增内部递归 `resolveStructFieldValue(nodeId, fieldName, depth)`**（struct 值域回溯，depth>8 熔断）：
   - 源 = struct.make：字段口被连线 → 连线优先递归 `resolvePortValue(源, 源handle)`（与 run 的「连线覆盖手填」一致）；否则按 fieldName 查 `data.fields`——`f.value` 非空 → 返回 `String(f.value)`；undefined/空串 → undefined
   - 源 = select.one：读 `data.pick`（如 "in1"）→ 找 pick 口入边 → 递归上游（pick 转发语义，与 run 的 `inputs[pick]` 一致）；不读遗留 lockType
   - 源 = struct.split：透传——沿其唯一 `struct` 输入口递归上游
   - 其余类型 → undefined
2. **`resolvePortValue` 连线源特判**：源是 struct.split 时 → `resolveStructFieldValue(源id, handleId)`（handleId 即 split 的动态出口 id=字段名）
3. 不给 selector/split/make 加 inferOutput 出口预览（多出口模型不适配单值 inferOutput，克制）；不加 node meta 字段

## 连带影响（有意的行为变化）
ssh.session 的 alias/refsPicker/scriptsPicker 门禁：输入从这条链来时 `want` 从 undefined（跳过校验）变为推导值（开始比对新鲜度）——正是防漂移门禁本意。
