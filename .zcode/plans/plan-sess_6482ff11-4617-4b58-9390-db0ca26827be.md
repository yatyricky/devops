# 修两个未解决的 bug（同一根因）+ 移除备注功能

## 根因（上一轮修复无效的原因）

上一轮引入的 `onstat` 回调在 stat effect 体内被调用（哪怕传 null），每次调用都新建 App 的 `stats` 对象 → App 全量重渲染 → xyflow 双向绑定回写节点对象 → DevNode 的 `data` 引用变化 → stat effect 再次执行 → 再次 `onstat` → **无限渲染循环**。循环中 stat 被持续打回 null（永远「查询中」、出口恒双口），节点测量被反复打断（只显示一个 node）。上次的 5s 超时和 {#key} 重挂都被这个循环掩盖，所以无效。

## 修复

1. **掐断循环**（App.svelte）：`onstat` 改为幂等——`stats[id]` 与新值等价（同引用，或 exists/isDir 相同）时**不更新**。首次上报与真实变化仍生效。
2. **stat effect 收窄**（DevNode.svelte）：effect 体内不再调用 `onstat(id, null)`（只在 fetch 成功/失败落定时上报一次）。
3. **移除备注功能**（用户要求）：删 DevNode 的备注脚本块、便利贴 markup、✍备注按钮、根节点 hover 事件与 `tick` 导入；删 app.css 的 `.notepop/.note` 样式。

## 收尾

重建 `web/dist`、跑 `npm run verify`（29 项）。
