# 新节点 dashboard.show：struct 汇总面板（讨论已定：struct 单口 / 字段名即标签 / boolean 状态徽章）

## 节点定义（engine/nodes/util.js 追加）
- `type: "dashboard.show"`，title「Dashboard」，工具类，色 #56b6c2
- inputs：`[{ id: "data", type: "struct", required: false }]`（纯 struct 收任意形状；未连线时面板显示占位提示）；outputs 无；widgets 无（零配置）
- run：展示节点无副作用 no-op（数据展示走既有 runNodeInputs 通道）
- 定义标记 `dashboardShow: true`；**engine/nodes/index.js nodeTypesMeta 白名单透传**（惯例同 sshAliasesPicker）

## 字段列表/值推导（复用既有派生链）
- **engine/rules.js** 新导出 `structFieldsFromShape(t)`：`struct:{k:type,...}` 形状串 → `[{key,type}]`（非形状串 null）
- **web/src/lib/infer.js**：makeInfer 返回值追加内部函数 `resolveStructFieldValue`（已实现，直接导出）
- **web/src/App.svelte context** 加两方法：
  - `structSourceOf(nodeId)`：data 口入边的源节点 id（null=未连线）
  - `resolveStructField(srcId, fieldName)` → infer().resolveStructFieldValue（编辑期常量推导）

## DevNode 渲染（`{#if meta?.dashboardShow}` 块，widgets 区位置）
- 字段列表：data 口入边源 → resolveOutputs(源)——源为 struct.split 时 outs 即字段列表；否则找形状串出口（struct.make/selector）→ structFieldsFromShape 解析
- 每字段一行（沿用 40/60 语言）：字段名左 40%（ellipsis+title）、值右 60% 右对齐、行间分隔线
- 值显示优先级：**运行中** `JSON.parse(ui.runNodeInputs[id].data)`（displayValue 已脱敏，SECRET 键为 `***`；解析失败回退运行中占位）→ **编辑期** resolveStructField 推导 → 都没有显示 `—`
- boolean → 状态徽章（true 绿 var(--ok) / false 红 var(--err) / 未设置灰）；number → mono；string → 文本
- 未连线/无字段：dim 占位「连接 struct 提供数据」
