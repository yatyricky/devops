# TriSwitch 状态机改为：undefined（仅初始态）→ true → false → true…

用户指定的状态机与当前实现差异：当前 tri 模式是 true→false→**undefined**→true 循环（会回到未设置态）；用户语义是 **undefined 只存在于从未点击的初始态**，首次点击进入布尔域后 true↔false 永久循环、不再出现 undefined。

## 改动

1. **web/src/TriSwitch.svelte**：点击处理改为 `onchange(value === true ? false : true)`（undefined/false→true，true→false）；删除 `tri` prop（新状态机下 tri 与二态行为完全重合，视觉本就由 value===undefined 驱动——按「不要冗余」原则移除）；注释更新为上述状态机。
2. **web/src/DevNode.svelte**：struct boolean 字段的 TriSwitch 去掉 `tri` 属性（唯一使用点）。
3. title 文案不变（未设置/true/false 三态照旧显示）。
