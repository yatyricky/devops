# 任务 = 子图选点（1 个或多个 DAG）+ 并发调度 + 4 项优化

## 核心语义变更（engine/workflow.js）

**数据模型**：`tasks[name]` 从 `{ label, mutates, path: 有序id[] }` 改为 `{ label, mutates, nodes: id集合 }`（顺序无关）。加载时旧 `path` 自动规范化为 `nodes`（三个迁移 JSON 一并迁移），旧文件无缝可载。

**任务子图构成**：nodes = 选点集合；edges = 两端都在选择内的边。入边按以下规则处理：
- **data 边指向 required 输入槽**（含动态插槽）：源必须已选，否则报错"节点 X 的必填输入依赖节点 Y，未选入"；
- **data 边指向非 required 输入槽**：源未选时**静默丢弃**（该输入在此任务中视作未连线，不报错）；
- **seq 边**：源或目标未选时静默丢弃（顺序约束自然失效）；两端都在则携带并参与定序。

**任务级三校验**（对构成的子图）：
1. **闭包**：即上面的 required 入边规则（原 case 1 选 3 / case 3 选 1,3 均因此报错）；
2. **插槽唯一**：任务内每个输入槽最多 1 条入边（≥2 报"只能有一个输入"——case 2 全选 123）；**required 输入必须恰好 1 条**（0 条报"必填输入未连线"，与闭包错误区分：前者是图上根本没画线，后者画了但源没选）；非 required 输入 0 条合法；
3. **无环**：Kahn 拓扑排序（data + seq 携带边都参与定序），有环报错。

同时：**删除**元图全局"同一输入多条连线"拒绝（大图是备选连线池，case 2 需要 1→2 与 3→2 并存）；**删除** seq 边与 path 顺序一致性检查。findTaskEnv 遍历 `task.nodes`。

**执行器重写**（executeTask）：拓扑层级并发调度——入度 0 的节点并发一批（Promise.allSettled），完成后释放下一层；任一节点失败，本批跑完后抛错终止（在途副作用由 finalize 收尾）；被丢弃的可选入边不提供输入值。旧 visiting/maxPathPos 前向依赖逻辑删除（闭包校验已保证子图自洽）。

## 前端（web/src）

- **App.svelte**：definer 从有序 path 改为节点集合——定义模式点击节点=切换选入/移出（不再沿 seq 自动追加）；浮层文案"点选节点（顺序无关）"；保存前用前端镜像校验（web/src/types.js 新增 `validateTaskSelection`：闭包[仅 required]/插槽唯一/无环，用 typeMap + effectiveInputs），错误红字显示，通过才写 `tasks[name] = { label, mutates, nodes }`；服务端仍是权威。
- **高亮**：任务悬停/定义高亮从 `{id: 序号}` 改为集合语义，DevNode 去掉序号徽章、保留虚线框；taskbar 按钮 hover 按任务名。
- **openRun**：运行输入只收集任务选中的 task.input 节点。
- **onConnect**：删除"输入已有连线"拒绝（大图允许多条备选连线）。
- **DevNode.svelte**：required 输入行加红星；widget `serializable: true` 渲染 `s` 徽章；pathCheck 放行 `~/` 前缀。
- **app.css**：`.svelte-flow__handle { cursor: default }`；星标与 `s` 徽章样式。

## 4 项优化

1. **~ 解析**：engine/exec.js 加 `expandHome(p)`（`~`/`~/`/`~\` → os.homedir()）；fs.path 与 `/api/fs/stat` 都过一遍；DevNode pathCheck 允许 `~` 开头。
2. **required 星标**：输入行红星（declared required + 动态插槽均标）。
3. **serializable**：widget 元数据可选 `serializable` 标志（nodeTypesMeta 原样透传 widgets，无需改）；已审核的 `fs.path.路径` 标 true；git.getRefs 的 ref 是 refsPicker UI 非 widget，天然无徽章。其余节点待你审核后补。
4. **指针**：handle 默认箭头。

## 周边同步

- 三个迁移 JSON：tasks `path` → `nodes`（脚本转换）。
- `cli.js`：tasks 命令显示节点集合（标注顺序无关）；注释同步；runner.js 注释同步。
- `tools/verify-dryrun.js`：三个 case 原样成测（fan-out 选 3 报闭包错/选 123、12 合法；双入大图合法、任务选 123 报"只能一个输入"、选 12 与 23 合法；链选 1,3 报闭包错）；**新增可选入边源不选→合法且输入为空**的用例（本次修正的行为）；required 未画线报"必填输入未连线"；seq 双向环报错；并发语义测（1→2,1→3 全执行且 1 先行、分支失败任务失败）；legacy path 规范化用例；三个迁移工作流 dry-run 不变。
- `docs/architecture.md`：执行语义段改为"任务 = 子图选点；required 闭包/插槽唯一/无环三校验；层内并发、层间拓扑序"。

## 设计取舍（如无异议按此执行）

- 可选输入槽在任务内 ≥2 条入边同样报错（歧义即错误）；0 条合法。
- 并发批内失败：等本批全部落地后抛第一个错误，不做中断强杀。
- 旧 `path` 字段加载时静默规范化。
