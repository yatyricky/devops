**SSH命令 textarea→input 上一轮已完成**（ssh.exec command kind text→string，实测已是单行 input），刷新 3010 即见。本轮只做 Make Struct 例外排版。

## 改动

### web/src/DevNode.svelte
1. widgets 循环的 `<label class="wrow nodrag">` 加条件类：`class:structrow={w.kind === "struct"}`（仅 struct 走例外）。
2. struct 分支的**字段值 input** 加 `class="fval"`（定宽标记；与 tri-switch 同槽互斥显示）。注释说明例外排版规则。

### web/src/app.css（新增规则）
1. `.wrow.structrow { display: block; }` + `.structrow .wlab { width: 100%; }`——**label 单独行、左对齐**（不再占 40%）。
2. `.structrow .tblwrap { width: 60%; margin-left: auto; }`——编辑区（含 spacing/padding）**右对齐合计 60%**。
3. `.structrow .trow > input:not(.fval), .structrow .trow > select { flex: 1 1 0; }`——**key input 与 type select 对半分**剩下宽度（＋新增行同构）。
4. `.structrow .trow > .fval { flex: none; width: 34px; }`——值 input 定宽 34px（与 tri-switch 同槽同宽，两种字段类型切换不跳行）；tri-switch/删除按钮/＋维持现有定宽（全局已有 flex:none）。
