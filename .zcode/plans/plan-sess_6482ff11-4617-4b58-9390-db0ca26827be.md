# Path Resolve 增加「路径风格」开关

## 改动（engine/nodes/util.js，单文件）

`path.resolve` 节点新增 serializable 枚举控件 `style`（posix / windows / auto，缺省 **auto**）：

- **posix**（缺省兼容）：输出 `/opt/x` 正斜杠形式——现有图的默认行为不变；
- **windows**：分隔符转反斜杠（`/opt/x` → `\opt\x`；有盘符段则 `C:\...`）；
- **auto**：拼接结果**首段带盘符**（如 `C:/...`）→ 输出 windows 风格；否则 posix（远端 Linux 路径场景不误伤）。

run 实现仅追加一行风格化（不影响拼接逻辑）；desc 同步说明。渲染端 widget 分支已支持 enum 下拉，无需改前端。

## 验证

- `npm run verify` 跑绿（既有 path.resolve 用例的 Windows 断言随 auto 缺省语义更新）；
- 补三条断言：posix 显式、windows 反斜杠、auto 判定（盘符段→windows 风格）。
