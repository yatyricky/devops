# textarea 增强特性 action 化（行号/高亮/自适应高度，可选择性应用）+ SSH命令应用

## 一、新模块 web/src/lib/textareaEnhance.js（独立可复用，零组件耦合）
Svelte action `export function enhance(node, params)`——**任意 textarea** 挂 `use:enhance={{ text, lineNumbers, highlight, autoGrow, maxHeight }}` 即得全部特性；params 各键独立开关：

- **highlight**：`"shell"`（内置高亮器：{{NAME}} 琥珀/命令词紫/字符串绿/注释灰斜体，纯函数 `highlightShell` 导出可替换为自定义 fn）或 falsy 关闭
- **lineNumbers**：按**逻辑行**标注（行号在每逻辑行首视觉行左；软换行续行向下、顶格——textarea 无悬挂缩进的取舍）——实现：隐形测量 pre（同宽/字体/pre-wrap，逐逻辑行 `<span>`）读 offsetTop → gutter 绝对定位行号；滚动同步 translateY
- **autoGrow**：mount+input+update 时 `height:auto→min(scrollHeight, maxHeight ?? 420)`（超出内部滚动）
- **结构自管**：action 自行把 textarea 包进 `.ta-enhance` 容器（gutter 列 + edit 区（pre 高亮层 + 隐形测量层 + textarea）），destroy 完整解包还原
- **update(params)**：text/开关变化时重算高亮、行号、高度（覆盖外部 programmatic value 更新，如 loadDoc）

## 二、样式（app.css 全局，锚定 action 注入的 class）
`.ta-enhance` 容器/gutter/edit/pre/measure 全套（现有 cmdhl 样式迁入并泛化：gutter 定宽 2.2em、pre 同字体/pre-wrap/overflow hidden、textarea 透明文字 caret 可见）

## 三、DevNode 接线（大幅简化）
- 删除内联的 highlightCmd/syncHlScroll/hlEls 与手写 pre 结构（~45 行）
- text 分支：`<textarea rows={w.rows ?? 4} use:enhance={{ text: get(w.key) ?? "", lineNumbers: !!w.lineNumbers, highlight: w.highlight, autoGrow: w.autoGrow }} ...>`——`w.highlight`/`w.lineNumbers`/`w.autoGrow` 均 widget 元数据开关（任意 textarea 可选择性应用）

## 四、SSH命令 widget 元数据
remote.js command：`kind:"text", fullrow:true, rows:2, highlight:"shell", lineNumbers:true, autoGrow:true`（本轮唯一应用点；其它 textarea 零改动、随时可开）
