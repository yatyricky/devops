## 改动（web/src/DevNode.svelte + web/src/app.css）

1. **`.wrow` 改横排**（app.css）：
   - `.wrow { display: flex; align-items: flex-start; gap: 6px; flex-wrap: wrap; margin-top: 6px; }`
   - `.wlab { flex: 0 0 40%; min-width: 0; ellipsis（已有）; margin-bottom: 0; align-self: center; }`

2. **`.kv.in` 统一右 60%**（app.css）：
   - `.kv.in .inlit { width: 60%; }`（原 50%）
   - `.kv.in .boolpair { width: 60%; justify-content: flex-end; }`（原 margin-left:auto 定宽）
   - pairrow 30%+30% 不动（合计恰 60%，正好成为全局基准）；`.selradio`/`.wired` 右贴齐不动
3. **label 截断 + title**（DevNode.svelte）：
